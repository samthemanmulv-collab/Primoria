# Primoria V7.1 Hotfix

This package is intended to fix the blank-app condition caused by mixed/stale deployments or a missing runtime dependency.

Changes:
- New v7.1 cache-busting asset URLs.
- New service-worker cache name.
- Service-worker installation no longer fails entirely if one optional cached file is missing.
- Home page handles missing course data instead of crashing.
- Runtime errors are surfaced in the page instead of leaving a blank content area.
- A fallback message appears if app.js does not start.

Deploy the entire extracted package to the repository root, preserving folders, commit to `main`, wait for GitHub Pages to finish, then clear the old site data/service worker once.
