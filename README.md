# Primoria Premier V4

## Included
- 49 lessons in modular school files
- Chronological journey with no forced locks
- Quick Read for short sessions
- Civilization map
- Story, Reading, Study, and Scholar modes
- Adjustable text size, spacing, width, and theme
- Profile dashboard stored locally
- First-run interest survey
- Interest-led or chronological recommendations
- Per-school progress and achievements
- Offline caching
- Text-based evidence reveal for quiz answers

## Upload to GitHub Pages
Replace the repository contents with this package, preserving the `content` folder. Commit and push.

## Privacy
The beta profile is stored only in browser local storage. It does not transmit a name, interests, or progress to a server.

## Editorial status
Interface functionality is ready for testing. Passages still marked pending require exact public-domain edition verification before being described as verified.
